KANA PRACTICE OFFLINE

This is an original offline-friendly kana practice app inspired by the study workflow of Tofugu's Learn Kana Quiz. It does not contain Tofugu source code, branding, artwork, or copied site assets.

QUICK TEST ON A COMPUTER
1. Unzip this folder.
2. Open a terminal in the folder.
3. Run: python3 -m http.server 8000
4. Visit http://localhost:8000

INSTALL ON IPHONE / IPAD
A service worker requires the app to be served over HTTPS (or localhost). Put this folder on GitHub Pages, Netlify, or another HTTPS host once. Then:
1. Open the HTTPS site in Safari.
2. Tap Share.
3. Tap Add to Home Screen.
4. Open the new home-screen app once while online.
5. After that, the app's core files work offline.

FEATURES
- Hiragana and katakana
- Main, dakuten, and combination kana
- Choose groups/columns to practice
- Typed romaji recall
- Wrong answers do not reveal the answer; keep trying
- Skip and revisit a character
- End-of-session trouble-character summary
- Offline PWA support
